# Milestone 1 — Protocol and authentication kernel

Status: complete on 2026-09-09.

Milestone 1 implements the CraftNet v1 wire and the authentication that rides on
it, in both languages, against one shared fixture catalog. No role behaviour
arrives here: nothing in this milestone knows what an address pool, a route, or
a NAT Flow is. That begins in Milestone 2.

## Delivered

### Shared fixture catalog

`spec/protocol/v1/` is the executable compatibility source of truth. It is
generated by `external/cmd/fixturegen` and replayed by both implementations:

| Fixture | Consumers | Covers |
|---|---|---|
| `cj1/canonical.json` | Lua, Go | 16 decode-then-encode round trips that must match byte for byte |
| `cj1/rejected.json` | Lua, Go | 22 inputs the canonical form cannot round trip |
| `hash/sha256.json` | Lua, Go | NIST FIPS 180-4 examples plus the three padding boundaries |
| `hash/hmac-sha256.json` | Lua, Go | RFC 4231 cases 1, 2, 3, 4, 6, and 7 |
| `derivation/keys.json` | Lua, Go | The whole purpose-separated derivation chain |
| `messages/accepted.json` | Lua, Go | One representative body for every v1 message kind |
| `messages/rejected.json` | Lua, Go | 26 scalar and structural rule violations |
| `frames/accepted.json` | Lua, Go | Correlated and uncorrelated authenticated frames |
| `frames/rejected.json` | Lua, Go | 13 tampering and version failures |
| `frames/sequences.json` | Lua, Go | Counter sequences that must fail closed |
| `handshake/enrollment.json` | Lua, Go | The four-message enrollment exchange and its credential |
| `handshake/session.json` | Lua, Go | The three-message reconnect and its session key |
| `limits/edges.json` | Lua, Go | Every structural bound, at the limit and one past it |
| `errors/catalog.json` | Lua, Go | The 23 stable v1 codes and their retryability |
| `gateway/frames.json` | Go | Gateway hello, welcome, and frame shapes |
| `tokens/access-token.json` | Go | Ed25519 Access Token issue and verification |

Published hash vectors are carried as literals from their standards rather than
computed, so they check the pure-Lua implementation instead of agreeing with it.
`scripts/check-fixtures.sh` regenerates the catalog into a temporary directory
and diffs, so the generator can never drift away from the checked-in files.

### `craftnet-protocol` (Lua)

Twelve modules behind one deliberately small interface. A caller opens an
enrolled link and exchanges semantic messages; it never calculates a MAC, a
counter, a body hash, an operational channel, or a canonical form.

- `bitops` — 32-bit word operations, using `bit32` on CC:Tweaked and nibble
  lookup tables elsewhere. No native bitwise operator appears, so the file parses
  on every supported host.
- `sha256`, `hmac` — FIPS 180-4 and RFC 2104, because CC:Tweaked exposes no
  hashing API. Constant-time MAC comparison.
- `cj1` — the strict decoder and canonical encoder. Byte-order key sorting is
  hand-rolled because Lua's own string comparison consults the C locale, which
  would make a signed preimage host dependent.
- `limits`, `errors` — the wire bounds and the stable code catalog.
- `schema` — every message kind, scalar rule, composite, and role configuration.
- `keys` — purpose-separated derivation and the exact signing preimages.
- `frame` — operational frames, handshake envelopes, discovery, and session
  counter state.
- `handshake` — both sides of enrollment and session establishment.
- `link` — correlation, timeouts, bounded in-flight work, over an injected
  transport and clock.

### `external/internal/protocol` (Go)

The same wire, independently implemented: CJ1, strict schemas, limits, the error
catalog, key derivation, operational frames, handshake envelopes, Gateway
framing, and Ed25519 Access Tokens. Go's crypto comes from the standard library;
the point of the shared catalog is that the two implementations agree anyway.

### Provisioning

`external/cmd/craftnetprov` writes a development World Key and Gateway
Credential bundle drawn from `crypto/rand`, so no CraftOS role invents a root
secret and no test credential leaks into a running World. The bundle is written
with owner-only permissions, refuses to overwrite an existing file, and is
identified in logs by an eight-character fingerprint rather than by any secret
value. Write it outside the repository, or into `data/`, which `.gitignore`
already excludes.

```bash
cd external && go run ./cmd/craftnetprov -out ../data/world.json
```

## Decisions made inside this milestone

Ticket 16 fixes the message shapes but leaves a few enumerations and internal
conventions open. These were settled here and are now wire constants:

- Role values are `central`, `isp`, `router`, `computer`.
- `topology_change.change` is `added`, `updated`, or `removed`;
  `entity_type` is `isp`, `customer_network`, `router`, or `computer`.
- `command_result.status` is `applied` or `rejected`.
- Traffic Event `direction` is `inbound`, `outbound`, or `local`.
- `request_id` is **omitted** from an uncorrelated frame rather than sent empty,
  because an empty string is not a valid CraftNet ID. The MAC preimage still uses
  the empty string, exactly as ticket 16 specifies.
- Derivation labels are `craftnet/v1/enrollment`, `.../relationship`,
  `.../session`, and `.../nonce`, each followed by a newline.
- A parent derives a child's one-time enrollment secret from its own root secret
  and a durable token-use counter, rather than storing a secret per child.
- The enrollment transcript carries `child_id` only when an existing logical
  child re-enrolls, so a first enrollment and a re-enrollment never derive the
  same credential.

## Deliberately deferred

- `craftnet-protocol` still declares its Milestone 0 dependency on `networking`,
  although the link takes an injected transport and references no modem. The
  modem adapter belongs to `craftnet-runtime` (ticket 13); the dependency edge
  moves in Milestone 3, when the runtime actually wires it and the ownership is
  demonstrable.
- The Go side implements Gateway framing and fixture conformance only. Session
  ownership, correlation, and command delivery are Milestone 6.

## Gate evidence

Lua and Go classify every shared fixture identically, and produce byte-identical
CJ1 wherever both participate.

```text
make fmt-check
make test
```

The Lua suite runs 53 tests and the Go suite covers `internal/protocol`,
`internal/provisioning`, `internal/fixtures`, and `internal/catalog`.

Interpreter and seed coverage:

```text
LUA_BIN=lua5.2  CRAFTNET_TEST_SEED=12648430 bash scripts/test-lua.sh
LUA_BIN=lua5.2  CRAFTNET_TEST_SEED=42       bash scripts/test-lua.sh
LUA_BIN=lua5.4  CRAFTNET_TEST_SEED=42       bash scripts/test-lua.sh
LUA_BIN=luajit  CRAFTNET_TEST_SEED=42       bash scripts/test-lua.sh
CRAFTNET_TEST_SEED=42 go test -race ./...
go vet ./...
```

Lua 5.2 supplies `bit32` and so exercises the path CC:Tweaked takes; 5.4, 5.5,
and LuaJIT exercise the arithmetic fallback. Both paths pass the same catalog.
CI runs both.

Gate requirements, and where each is proven:

| Requirement | Evidence |
|---|---|
| Both languages classify every fixture identically | `spec/protocol/v1` replayed by `tests/lua/protocol_conformance_test.lua` and `external/internal/protocol/conformance_test.go` |
| Byte-identical CJ1 where both participate | `cj1/canonical.json`; goldens generated by Go, reproduced by Lua |
| Published SHA and HMAC vectors pass | `hash/sha256.json`, `hash/hmac-sha256.json` |
| A changed field, body, counter, relationship, or session fails authentication | `frames/rejected.json`, 13 cases |
| Replay and out-of-order counters fail closed | `frames/sequences.json`; `protocol_handshake_test.lua` |
| Exactly-limit frames pass; oversized, deep, sparse, and unknown-control frames fail with their specified errors | `limits/edges.json`, `cj1/rejected.json`, `frames/rejected.json`, `protocol_codec_test.lua` |
| No caller outside the package handles MACs or canonicalization | `tests/lua/protocol_encapsulation_test.lua` |

The malformed-fixture negative path still passes, and the catalog validator now
also rejects a fixture with no consumer, an unknown consumer, and a package
source file that ships without being listed in its manifest.

## A note on cost

The pure-Lua SHA-256 is the expensive part of every message. On a desktop CPU
under Lua 5.2 with `bit32`, a digest of a frame at the full 16 KiB modem ceiling
takes roughly 32 ms; ordinary CraftNet frames are one to two orders of magnitude
smaller. The whole Lua suite runs in about 2.2 seconds. No optimization was
attempted here beyond choosing `bit32` when the host offers it and nibble tables
when it does not. Measured in-world cost belongs to the Milestone 8 scale work,
which is where a real budget can be set against a real topology.

Milestone 2 is the next implementation gate: `craftnet-core` as pure role state
transitions, and the deterministic multi-role simulator around `engine:handle`.
